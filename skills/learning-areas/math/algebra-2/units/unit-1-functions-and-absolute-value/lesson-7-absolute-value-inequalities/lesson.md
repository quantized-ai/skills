# Lesson 1.7: Absolute value inequalities

[Unit 1: Function language, transformations, and absolute value](../unit.md) · [Algebra 2](../../../curriculum.md)

Absolute value inequalities describe points inside or outside a distance interval. Logical connectors, exceptional bounds, and endpoint inclusion determine the complete solution set.

## Learning objectives

- Solve absolute value linear inequalities through distance and case reasoning.
- Express and justify the resulting sets with correct logical connectors and endpoints.

## Learning outcome

By the end of this lesson, you should be able to derive the complete real solution set of an absolute value linear inequality and explain its interval structure.

## Proficiency criteria

To demonstrate proficiency, the student must independently satisfy all of the following criteria.

- Isolate the absolute value with valid inequality operations, reversing the comparison whenever division or multiplication by a negative quantity requires it.
- Determine the consequence of a negative or zero isolated bound from nonnegativity before using a two-case rule.
- Use an intersection for an interior distance condition and a union for an exterior condition, distinguishing strict from inclusive comparisons.
- Give an equivalent interval or set description with all allowed components and no inadmissible endpoints.

## Concepts

### Concept U01-L07-C01: Interior and exterior distance intervals

**Content**

- $|u|<c$ as an intersection and $|u|>c$ as a union for $c>0$.
- Inclusive endpoints, negative outside coefficients, and nonpositive bounds.
- Interval solutions and tests in the original inequality.

**Learning objectives**

- **U01-L07-C01-O1:** Solve absolute value linear inequalities and represent solutions in interval notation.
  - Standards: TEKS 2A.6(F) (direct); TEKS 2A.7(I) (supporting knowledge).
- **U01-L07-C01-O2:** Justify conjunctions, disjunctions, and exceptional cases using the distance interpretation.
  - Standards: TEKS 2A.6(F) (direct).

**Proficiency criteria**

- Isolate the absolute value using equivalence-preserving inequality operations, including sign reversal when required.
- Resolve negative and zero bound cases from nonnegativity and strictness before applying interior or exterior interval rules.
- Use conjunction for an interior distance condition and disjunction for an exterior condition, with all sign cases represented.
- State the complete solution set with correct finite endpoint inclusion and explain it using distance.

**Explanation**

Distance less than $c$ means being inside an interval: $-c<u<c$. Distance greater than $c$ means being outside: $u<-c$ or $u>c$. Inclusive symbols retain endpoints. Check the isolated bound before applying these rules: $|u|<-1$ is impossible, whereas $|u|>-1$ is always true. Dividing an inequality by a negative number reverses its direction.

**Worked examples**

$|2x-1|\le5$ gives $-5\le2x-1\le5$, then $-2\le x\le3$. For $-2|x+1|<-6$, division by $-2$ gives $|x+1|>3$, hence $x<-4$ or $x>2$.

**Exercises**

1. Solve $|x-4|\ge2$. **Answer:** $(-\infty,2]\cup[6,\infty)$.
2. Solve $|x+2|\le0$ and $|x+2|\ge0$. **Answer:** $\{-2\}$ and $\mathbb R$, respectively.

**Assessment**

Solve $3-2|x-1|\ge-5$, express the answer in interval notation, and verify an endpoint and an excluded input. **Expected:** $|x-1|\le4$, so $[-3,5]$; at $5$ equality holds; at $6$ the left side is $-7<-5$. **Rubric, 4 points:** correct reversal and interval (2; O1), distance logic and checks (2; O2).
