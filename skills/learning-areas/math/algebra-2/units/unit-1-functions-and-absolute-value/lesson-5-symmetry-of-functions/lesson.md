# Lesson 1.5: Symmetry of functions

[Unit 1: Function language, transformations, and absolute value](../unit.md) · [Algebra 2](../../../curriculum.md)

Even and odd functions express symmetry through identities. The symmetry of the domain is part of the test, and the available representation determines how strong the evidence can be.

## Learning objectives

- Test evenness and oddness using the domain and function identities.
- Connect algebraic classifications to symmetry in graphs and tables.

## Learning outcome

By the end of this lesson, you should be able to justify an even, odd, both, or neither classification with evidence valid over the stated domain.

## Proficiency criteria

To demonstrate proficiency, the student must independently satisfy all of the following criteria.

- Check that the domain contains the negative of each allowed input before applying an even or odd identity.
- Compare the substituted rule with the original rule and its negative, preserving signs and grouping.
- Relate evenness to reflection across the vertical axis and oddness to symmetry about the origin, including the possibility of both.
- Distinguish a proof over the domain from a pattern observed in only a few points of a larger unspecified function.

## Concepts

### Concept U01-L05-C01: Even and odd functions

**Content**

- $f(-x)=f(x)$ and $f(-x)=-f(x)$.
- Domain symmetry about zero.
- $y$-axis and origin symmetry; neither and both cases.

**Learning objectives**

- **U01-L05-C01-O1:** Test evenness and oddness algebraically, including the domain requirement.
  - Standards: CCSS HSF-BF.B.3 (direct).
- **U01-L05-C01-O2:** Connect these identities to symmetry in a graph or table.
  - Standards: CCSS HSF-BF.B.3 (direct).

**Proficiency criteria**

- Establish that the domain is symmetric under input negation before testing either identity.
- Substitute the negated input and compare the result with the original output and its negative using valid algebra.
- Classify the function as even, odd, both, or neither and relate the result to the appropriate graph symmetry.
- Limit a finite table’s symmetry claim to its stated domain unless additional evidence establishes the rule elsewhere.

**Explanation**

First check that whenever $x$ is in the domain, $-x$ is also there. Then compare formulas. An even function has mirrored points $(x,y)$ and $(-x,y)$; an odd function has points $(x,y)$ and $(-x,-y)$. A symmetric finite table supports the corresponding pattern for its listed domain; a few table entries cannot prove symmetry of an unspecified continuous function. The zero function on a symmetric domain is both even and odd.

**Worked examples**

For $f(x)=x^2+2$ on $\mathbb R$, $f(-x)=x^2+2=f(x)$, so it is even. For $g(x)=x^3-x$, $g(-x)=-x^3+x=-g(x)$, so it is odd. The same formula $x^2+2$ restricted to $[0,3]$ is not classified as even because its domain is not symmetric.

**Exercises**

1. Classify $h(x)=x^2+x$ on $\mathbb R$. **Answer:** Neither: $h(-x)=x^2-x$ is neither $h(x)$ nor $-h(x)$.
2. An odd function has $f(4)=-7$. Find $f(-4)$ and, if defined, $f(0)$. **Answer:** $7$ and $0$.

**Assessment**

Classify $p(x)=x^4-3x^2$ on $\mathbb R$ and justify algebraically. If $(2,4)$ is on its graph, give the symmetry-related point. Explain why restricting the domain to $[0,5]$ changes the symmetry classification. **Expected:** Even; $p(-x)=p(x)$; $(-2,4)$; the restricted domain lacks opposite inputs. **Rubric, 4 points:** identity/domain analysis (2; O1), graphical interpretation (2; O2).
