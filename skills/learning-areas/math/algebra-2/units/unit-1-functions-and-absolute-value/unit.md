# Unit 1: Function language, transformations, and absolute value

[Algebra 2](../../curriculum.md)

This unit establishes the function language used throughout Algebra 2, then applies it to transformations, absolute value, and piecewise rules. Domain, range, endpoint inclusion, and the distinction between a graph feature and a contextual interpretation recur in later units.

## Prerequisites

Signed-number arithmetic, substitution, distribution, linear equations and inequalities, and coordinates. Lessons 1.1–1.3 include prerequisite review; use the entry diagnostic to adjust practice.

## Main learning objectives

These objectives summarize the learning objectives in the linked lessons.

- Classify and evaluate functions while expressing domain and range precisely. Lessons [1.1](lesson-1-relations-and-function-notation/lesson.md), [1.2](lesson-2-sets-intervals-domain-and-range/lesson.md).
- Interpret graph features and average rates without confusing local behavior with net change. Lessons [1.3](lesson-3-features-and-change-in-functions/lesson.md).
- Predict transformations and test symmetry through consistent formulas, points, and domains. Lessons [1.4](lesson-4-transformations-of-functions/lesson.md), [1.5](lesson-5-symmetry-of-functions/lesson.md).
- Represent distance with absolute value graphs, equations, and inequalities. Lessons [1.6](lesson-6-absolute-value-functions-and-equations/lesson.md), [1.7](lesson-7-absolute-value-inequalities/lesson.md).
- Evaluate and construct piecewise and step rules with correct boundary membership. Lessons [1.8](lesson-8-piecewise-and-step-functions/lesson.md).

## Concepts and topics

Input-output relations; function notation; sets and intervals; intercepts and extrema; average rate; translations, reflections, and scale factors; even and odd symmetry; absolute value; piecewise and step functions.

## Lessons

- [1.1: Relations and function notation](lesson-1-relations-and-function-notation/lesson.md) — Relations establish which inputs are allowed and whether each has a unique output.
- [1.2: Sets, intervals, domain, and range](lesson-2-sets-intervals-domain-and-range/lesson.md) — Set notation makes domain and range statements precise.
- [1.3: Features and change in functions](lesson-3-features-and-change-in-functions/lesson.md) — Function features describe where outputs lie and how they change.
- [1.4: Transformations of functions](lesson-4-transformations-of-functions/lesson.md) — Input and output transformations connect formulas, corresponding points, and graph features.
- [1.5: Symmetry of functions](lesson-5-symmetry-of-functions/lesson.md) — Even and odd functions express symmetry through identities.
- [1.6: Absolute value functions and equations](lesson-6-absolute-value-functions-and-equations/lesson.md) — Absolute value connects distance, a two-branch graph, and equations with separate sign cases.
- [1.7: Absolute value inequalities](lesson-7-absolute-value-inequalities/lesson.md) — Absolute value inequalities describe points inside or outside a distance interval.
- [1.8: Piecewise and step functions](lesson-8-piecewise-and-step-functions/lesson.md) — Piecewise definitions assign formulas to input regions; step functions assign constant outputs to such regions.
