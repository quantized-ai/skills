# Standards: Lesson 1.6 — Absolute value functions and equations

Mappings for the concepts and learning objectives in [Lesson 1.6](lesson.md).

**CCSS:** Common Core mathematics standards. **TEKS:** Texas standards. Mapping labels retain direct coverage, prerequisite review, or supporting knowledge as specified.

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| **Absolute value as distance and a piecewise rule** | Explain absolute value as distance and graph its transformed functions with vertex, slopes, intercepts, domain, and range. | CCSS HSF-IF.C.7b (direct); TEKS 2A.2(A) (direct). |
| **Absolute value as distance and a piecewise rule** | Explain the effects of nonzero inside and outside multipliers and translations on an absolute value graph. | CCSS HSF-BF.B.3 (direct); TEKS 2A.6(C) (direct). |
| **Absolute value equations** | Formulate an absolute value linear equation from an exact-distance condition. | TEKS 2A.6(D) (direct); CCSS HSA-CED.A.1 (direct). |
| **Absolute value equations** | Solve absolute value linear equations by isolating the absolute value, resolving sign cases, and verifying candidates and solution counts. | TEKS 2A.6(E) (direct); CCSS HSA-REI.B.3 (supporting knowledge). |
