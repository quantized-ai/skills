# Standards: Lesson 15.3: Exact special-angle values

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| Special triangles | Derive exact values at $\pi/4$, $\pi/6$, and $\pi/3$ using the Pythagorean theorem, special triangles, and normalization to unit hypotenuse. | CCSS HSF-TF.A.3 (+, direct). |
| Special triangles | Calculate exact sine, cosine, and tangent values from special-triangle ratios without decimal approximation. | CCSS HSF-TF.A.3 (+, direct). |
| Reference angles and reflected coordinates | Use unit-circle reflections and half-turn rotations to express trigonometric ratios at related angles and justify their signs. | CCSS HSF-TF.A.3 (+, direct). |
| Reference angles and reflected coordinates | Find exact values at special-angle terminal positions, including negative, multi-turn, and axis inputs, and identify undefined tangent. | CCSS HSF-TF.A.3 (+, direct). |
