# Unit 5 assessment

[Unit overview](unit.md)

## Cumulative unit assessment

Administer after the concept checks, without worked examples visible. Require intermediate reasoning, not only final answers. For sketches, accept hand-drawn or technology-produced graphs only when the requested features are justified. Optional extension points are reported separately from core scores.

1. **Task:** Rewrite $-2x^2+8x-6$ in vertex and factored forms; sketch with all intercepts and give range.
   - **Expected answer:** $-2(x-2)^2+2=-2(x-1)(x-3)$; vertex $(2,2)$, intercepts $(0,-6),(1,0),(3,0)$, range $(-\infty,2]$.
   - **Scoring:** 4 points: forms 2, sketch/features and range 2.
2. **Task:** Construct a quadratic through $(0,3),(1,2),(2,5)$.
   - **Expected answer:** $2x^2-3x+3$; substitution verifies each point.
   - **Scoring:** 4 points: equations 1, solution 2, verification 1.
3. **Task:** Derive the equation of the parabola with focus $(2,5)$ and directrix $y=1$.
   - **Expected answer:** $(x-2)^2+(y-5)^2=(y-1)^2$ gives $(x-2)^2=8(y-3)$; vertex $(2,3)$.
   - **Scoring:** 4 points: distance equality 2, equation/vertex 2.
4. **Task:** Find all attributes of $y^2-2y+12x+25=0$ and explain whether it is a function of $x$.
   - **Expected answer:** $(y-1)^2=-12(x+2)$; vertex $(-2,1)$, $p=-3$, focus $(-5,1)$, directrix $x=1$, axis $y=1$, opens left; not a function of $x$.
   - **Scoring:** 4 points: conversion 1, attributes 2, function explanation 1.
5. **Task:** Solve $x^2+3x-10\ge0$ and $(x-4)^2<0$, explaining endpoints.
   - **Expected answer:** First $(-\infty,-5]\cup[2,\infty)$; second empty because a real square cannot be negative.
   - **Scoring:** 4 points: sign analysis 2, sets/endpoints 2.

**Instructional response:** A secure response earns at least 80% of core cumulative points and at least 3/4 on every concept check. Re-teach any missed objective using its explanation and a new numerical instance before reassessment; do not allow a high total to conceal an unassessed objective.
