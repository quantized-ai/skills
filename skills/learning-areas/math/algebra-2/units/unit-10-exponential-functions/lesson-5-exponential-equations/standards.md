# Standards: Lesson 10.5: Exponential equations

CCSS refers to Common Core mathematics standards; TEKS refers to Texas standards. Mapping classifications are retained for each learning objective.

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| Common-base equations | Solve exponential equations by rewriting both sides with the same positive base different from one and recognize targets excluded by positivity. | TEKS 2A.5(D) (direct); CCSS HSN-RN.A.2 (supporting knowledge). |
| Common-base equations | Justify equating exponents and verify candidate solutions in the original equation. | CCSS HSA-REI.A.1 (direct); TEKS 2A.5(D) (direct). |
| Graphical and numerical solutions | Approximate an exponential-equation solution using a graph or table and verify it against the original outputs. | CCSS HSA-REI.D.11 (direct); TEKS 2A.5(D) (direct). |
| Graphical and numerical solutions | Report a valid bracket, justify numerical precision, and establish uniqueness when the functions’ behavior supports it. | CCSS HSA-REI.D.11 (direct); CCSS HSN-Q.A.3 (direct). |
