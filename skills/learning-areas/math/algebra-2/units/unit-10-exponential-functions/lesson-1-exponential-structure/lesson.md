# Lesson 10.1: Exponential structure

Exponential functions place the variable in an exponent. Their values change by a constant multiplicative factor over equal input intervals; the interval length determines which factor is being compared.

## Learning objectives

- Distinguish exponential functions from power and polynomial functions and evaluate them.
- Use equal-interval ratios to identify an exponential pattern, recover its per-unit factor, and state the limits of finite data.

## Learning outcome

Recognize exponential structure and connect a multiplicative factor to its input interval.

## Proficiency criteria

- Apply the nonconstant exponential family’s coefficient and base conditions.
- Evaluate positive, zero, and negative inputs using exponent laws.
- Compare ratios over equal input increments and recover the positive per-unit factor.
- Distinguish multiplicative patterns from additive patterns and from proof of a unique model.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Exponential functions versus power functions** | A nonconstant real exponential has form $f(x)=ab^x$ with $a\ne0$, $b>0$, and $b\ne1$, and domain $\mathbb R$. The variable is in the exponent; a power function has a variable base and fixed exponent. Base $1$ or coefficient $0$ makes this formula constant. A negative base does not define this all-real-domain family. Zero exponents give $1$; negative exponents give reciprocals. | Distinguish exponential functions from power and polynomial functions using their variable placement and parameter conditions. Evaluate exponential functions at positive, zero, and negative inputs. | Identify the variable’s position and apply the coefficient and base conditions. Explain the exclusions of constant cases and negative bases. Evaluate the full expression, using reciprocals for negative exponents. |
| **Equal-interval ratios** | For $f(x)=ab^x$ with $a\ne0$, $b>0$, and $b\ne1$, $f(x+h)/f(x)=b^h$. Equal input increments therefore give equal positive output ratios; for interval length $h>0$, a ratio $q$ gives per-unit factor $b=q^{1/h}$. Constant first differences indicate a linear pattern. A finite table can be consistent with an exponential model without uniquely determining the function at unlisted inputs. | Test equal-step tables for exponential behavior using ratios and distinguish pattern evidence from a unique-model claim. Explain the multiplicative factor over an arbitrary input interval and recover the per-unit factor. | Check input spacing and nonzero outputs before comparing ratios. Relate a ratio to its interval length and recover the positive per-unit factor. Distinguish constant ratios from constant differences and acknowledge the limits of finite data. |
