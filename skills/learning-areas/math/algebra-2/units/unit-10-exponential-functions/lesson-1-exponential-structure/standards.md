# Standards: Lesson 10.1: Exponential structure

CCSS refers to Common Core mathematics standards; TEKS refers to Texas standards. Mapping classifications are retained for each learning objective.

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| Exponential functions versus power functions | Distinguish exponential functions from power and polynomial functions using their variable placement and parameter conditions. | CCSS HSF-LE.A.1 (supporting knowledge); TEKS 2A.5(B) (supporting knowledge). |
| Exponential functions versus power functions | Evaluate exponential functions at positive, zero, and negative inputs. | CCSS HSF-IF.A.2 (direct); TEKS 2A.2(A) (supporting knowledge). |
| Equal-interval ratios | Test equal-step tables for exponential behavior using ratios and distinguish pattern evidence from a unique-model claim. | CCSS HSF-LE.A.1a (direct). |
| Equal-interval ratios | Explain the multiplicative factor over an arbitrary input interval and recover the per-unit factor. | CCSS HSF-LE.A.1a (direct); CCSS HSF-IF.C.8b (direct). |
