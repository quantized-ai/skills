# Standards: Lesson 16.8: Prediction and model revision

Mappings for the concepts and learning objectives in [Lesson 16.8](lesson.md).

**CCSS:** Common Core mathematics standards. **TEKS:** Texas standards. **Direct:** the objective addresses the standard. **Supporting knowledge:** the objective provides a foundation for the standard.

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| **Interpolation, extrapolation, and uncertainty** | Calculate model predictions, check their contextual feasibility, and classify them as interpolation or extrapolation relative to observed inputs. | TEKS 2A.8(C) (direct); CCSS HSS-ID.B.6a (direct). |
| **Interpolation, extrapolation, and uncertainty** | Critique prediction reliability and reporting precision using data coverage, model assumptions, residual variation, and sensitivity to model choice. | TEKS 2A.8(C) (direct); CCSS HSF-IF.B.5 (direct). |
| **Model comparison and documented revision** | Compare competing models using common-scale data fit, contextual mechanisms, domain constraints, and additional validation observations when available. | TEKS 2A.8(A) (direct); TEKS 2A.8(C) (direct). |
| **Model comparison and documented revision** | Communicate a justified selection or revision with variables, units, equation, fitting method, assumptions, evidence, usable domain, and limitations. | CCSS HSA-CED.A.2 (direct); TEKS 2A.8(C) (direct). |
