# Standards: Lesson 16.3: Function-family selection

Mappings for the concepts and learning objectives in [Lesson 16.3](lesson.md).

**CCSS:** Common Core mathematics standards. **TEKS:** Texas standards. **Direct:** the objective addresses the standard. **Supporting knowledge:** the objective provides a foundation for the standard.

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| **Differences, ratios, shape, and context** | Select linear, quadratic, or exponential candidates from equally spaced data using appropriate differences or ratios and recognize when those tests do not apply. | TEKS 2A.8(A) (direct); CCSS HSS-ID.B.6a (direct). |
| **Differences, ratios, shape, and context** | Justify or reject a candidate using graph shape, contextual mechanisms, domain limits, and the limits of finite-data evidence. | TEKS 2A.8(A) (direct); CCSS HSF-IF.B.4 (direct). |
| **Comparing representations and rates** | Calculate and interpret average rates of change over specified intervals with correct units and limits of interpretation. | CCSS HSF-IF.B.6 (direct). |
| **Comparing representations and rates** | Compare models represented in different forms using rates, output levels, and key graph features supported by each representation. | CCSS HSF-IF.C.9 (direct); CCSS HSF-IF.B.4 (direct). |
| **Extrema on specified intervals** | Determine interval maxima and minima of square-root, reciprocal, cubic, cube-root, absolute-value, exponential, and logarithmic parent functions using domain restrictions and graph behavior. | TEKS 2A.2(A) (direct); CCSS HSF-IF.B.4 (supporting knowledge). |
| **Extrema on specified intervals** | Compare extrema with their attaining inputs and distinguish attained values, unattained bounds, and unbounded behavior. | CCSS HSF-IF.C.9 (direct); TEKS 2A.2(A) (direct). |
