# Standards: Lesson 16.5: Regression foundations and linear fitting

Mappings for the concepts and learning objectives in [Lesson 16.5](lesson.md).

**CCSS:** Common Core mathematics standards. **TEKS:** Texas standards. **Direct:** the objective addresses the standard. **Supporting knowledge:** the objective provides a foundation for the standard.

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| **Data entry, residuals, and least squares** | Prepare paired data and a scatter plot, identify the model form, and calculate reproducible predictions and signed residuals. | TEKS 2A.8(B) (supporting knowledge); CCSS HSS-ID.B.6b (direct). |
| **Data entry, residuals, and least squares** | Compare candidate fits using squared residuals on a common data set and response scale, explaining least squares and limits of fitting-data evidence. | TEKS 2A.8(C) (direct); CCSS HSS-ID.B.6b (direct). |
| **Linear regression and coefficient interpretation** | Use technology to calculate an intercept-including linear regression and verify its coefficients through regression sums or an equivalent reproducible calculation. | TEKS 2A.8(B) (direct); CCSS HSS-ID.B.6c (direct). |
| **Linear regression and coefficient interpretation** | Interpret regression slope and intercept in units and make contextual predictions from stored coefficients, identifying unsupported intercept interpretations. | CCSS HSS-ID.C.7 (direct); TEKS 2A.8(C) (direct). |
