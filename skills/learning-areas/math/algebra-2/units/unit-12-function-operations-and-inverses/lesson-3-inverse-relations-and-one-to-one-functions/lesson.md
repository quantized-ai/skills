# Lesson 12.3: Inverse relations and one-to-one functions

An inverse relation reverses input-output pairs. It is an inverse function exactly when the original function is one-to-one on its stated domain; its domain is the original range.

## Learning objectives

- Determine and justify whether a function has an inverse function on its stated domain; distinguish inverse and reciprocal notation.
- Read and graph inverse values by reversing pairs and exchanging complete domain and range sets.

## Learning outcome

Justify an inverse function’s existence and represent it accurately from the original mapping, table, or graph.

## Proficiency criteria

- Test one-to-one behavior on the stated domain using algebra, ordered pairs, or the horizontal line test.
- Distinguish an inverse relation from an inverse function and an inverse function from a reciprocal.
- Read inverse values and reflect coordinates across $y=x$.
- Exchange domain and range, preserving exclusions and endpoints; do not infer unprovided values from a finite table.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **When an inverse is a function** | An inverse relation swaps each ordered pair. It is a function on the original range exactly when the original function is one-to-one: distinct allowed inputs have distinct outputs, equivalently $f(a)=f(b)$ implies $a=b$. The horizontal line test checks this on a graph. $f^{-1}$ denotes the inverse mapping, whereas $1/f$ denotes reciprocal output values where $f\ne0$. | Determine and justify whether a function has an inverse function on its stated domain, distinguishing it from an inverse relation. Distinguish inverse notation from a reciprocal and identify the original range as the inverse domain. | Justify one-to-one behavior or give a valid pair of distinct inputs with equal outputs. Connect that condition to a single-output inverse relation. Distinguish inverse and reciprocal mappings and state the inverse domain. |
| **Inverse values from tables and graphs** | For a one-to-one function, $f(a)=b$ means $f^{-1}(b)=a$. Swapping graph coordinates reflects the graph across $y=x$. The inverse domain is the complete original range and the inverse range is the complete original domain, including excluded values and endpoint inclusion. A finite table defines only its listed pairs unless further behavior is specified. | Read inverse values from a table or graph of a one-to-one function without assuming unprovided values. Graph an inverse by reflection across $y=x$ and exchange domain and range with all endpoint and exclusion conditions. | Locate the original pair for each inverse value and reverse its coordinates. Reflect across the diagonal correctly. Exchange complete sets and preserve finite membership, exclusions, and open or closed endpoints. |
