# Standards: Lesson 12.3: Inverse relations and one-to-one functions

Mappings for the concepts and learning objectives in [Lesson 12.3](lesson.md).

**CCSS:** Common Core mathematics standards. **TEKS:** Texas standards. **Direct:** the objective addresses the standard. **Supporting knowledge:** the objective provides a foundation for the standard. A **(+)** marker is part of the standard designation and does not make this lesson optional.

| Concept | Learning objectives | Standards |
| --- | --- | --- |
| **When an inverse is a function** | Determine and justify whether a function has an inverse function on its stated domain, distinguishing it from an inverse relation. | CCSS HSF-BF.B.4a (supporting knowledge); TEKS 2A.2(B) (supporting knowledge). |
| **When an inverse is a function** | Distinguish inverse notation from a reciprocal and identify the original range as the inverse domain. | TEKS 2A.2(B) (direct); CCSS HSF-BF.B.4a (supporting knowledge). |
| **Inverse values from tables and graphs** | Read inverse values from a table or graph of a one-to-one function without assuming unprovided values. | CCSS HSF-BF.B.4c (+) (direct); TEKS 2A.2(B) (direct). |
| **Inverse values from tables and graphs** | Graph an inverse by reflection across $y=x$ and exchange domain and range with all endpoint and exclusion conditions. | TEKS 2A.2(B) (direct); TEKS 2A.2(C) (direct). |
