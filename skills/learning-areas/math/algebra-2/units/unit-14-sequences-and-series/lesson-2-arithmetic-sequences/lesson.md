# Lesson 14.2: Arithmetic sequences

Arithmetic sequences describe constant additive change per index step. Explicit and recursive forms encode the same initial value, common difference, and indexing convention.

## Learning objectives

- Construct and verify arithmetic rules from consecutive or separated terms, recognizing the limits of finite evidence.
- Translate between explicit and recursive forms while preserving the starting index.
- Interpret initial values and common differences in discrete models.

## Learning outcome

Construct, translate, evaluate, and interpret arithmetic sequence models with a consistent index convention.

## Proficiency criteria

- Determine the per-step difference from equal or unequal index gaps under an arithmetic-model assumption.
- Construct a rule that reproduces all supplied terms and use it to calculate requested terms.
- Translate forms without changing the starting index or number of increments.
- Interpret the initial value and common difference in the model’s quantities.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| Constant differences and explicit formulas | An arithmetic sequence has constant one-step difference $d$. With first index $m$, $a_n=a_m+(n-m)d$; the usual index-one form is $a_n=a_1+(n-1)d$. Under an arithmetic-model assumption, two terms at distinct indices give $d=(a_k-a_j)/(k-j)$. Finite agreement supports a model but does not determine every possible continuation. | Determine a common difference, construct and verify an explicit arithmetic rule, and explain the limits of finite data. Calculate indexed terms of an arithmetic sequence, including when the given terms are nonconsecutive. | Account for index gaps when computing the one-step difference; use the correct number of increments from the stated initial index; reproduce all supplied terms and evaluate the requested term; distinguish a fitted arithmetic model from a uniquely determined continuation. |
| Arithmetic recursive and explicit representations | With initial value $a_m$, the recursion $a_n=a_{n-1}+d$ for $n>m$ and explicit rule $a_n=a_m+(n-m)d$ describe the same sequence on its integer domain. The common difference is change per index step. In a rule written as $a_n=b+dn$, $b$ is the formula’s value at zero; it is a sequence term only if zero is an allowed index and need not be the first observed term. | Translate arithmetic sequences between recursive and explicit forms with consistent indices and domains. Build and interpret an arithmetic model, including its initial value and change per index step. | Preserve the initial index, initial value, common difference, and domain when translating; explain the offset $n-m$ as a count of additions; interpret parameters in context and verify both forms at a shared input. |
