## Reasoning and error-analysis activity

**Ask:** Multiplying all measurements by−2 is said to make SD negative. Ask the student to locate the first invalid inference, repair the reasoning, and explain a check or counterexample.

**Private reasoning and response:** SD scales by absolute factor 2; variance by4. Ask whether distance can be negative, then calculate a small transformed dataset.

If the student gives only a corrected answer, ask why the original method failed. If the reason is secure, request a different example where the distinction matters. If they remain stuck, use the targeted response below for the relevant concept and mark the attempt assisted.

## Concept teaching plans

### Variance and standard deviation

**Diagnostic — ask and wait:** For population 2,4,6, variance and SD?

**Private diagnostic key:** 8/3 and √(8/3).

**Teach in this order:** Compute deviations in a table; square/sum; choose purpose-based denominator; root only after averaging.

**Distinct worked model — reveal in steps:** Sample 1,3,5,7 has mean 4, squared deviations 9+1+1+9=20. Sample variance 20/3, s=√(20/3). Population variance for the same complete set would 5. SD returns to original units; variance is squared units.

**Misconception response and hint ladder:** If average absolute deviation is substituted, ask which measure squares distances; next compare 2² versus|2|.

**Practice progression:** Population computation → sample convention → compare units and transformations. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** n versus n−1; n>1 sample; units; nonnegative values; no rounding before final root. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Identify the intended denominator, distinguish squared units from original units, and select the matching technology output rather than interchange sample and population values.

### Comparing shape, center, and spread

**Diagnostic — ask and wait:** Can two distributions have the same mean but different spread?

**Private diagnostic key:** yes;0,5,10 and 4,5,6 both mean 5.

**Teach in this order:** Inspect displays before choosing summaries; compare corresponding measures and units; connect shape to resistance of summaries.

**Distinct worked model — reveal in steps:** Compare symmetric A:2,3,4,5,6 and skewed B:2,3,4,5,21. Both medians 4, but B has a right tail and much larger mean 7. A contextual comparison should name shape, center, spread and unusual values rather than rank only means.

**Misconception response and hint ladder:** If the larger mean is called 'more consistent', ask which statistic measures variability; next compare ranges or SDs.

**Practice progression:** Same center/different spread → skew/outlier comparison → contextual summary with justified measures. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Shape/center/spread together; compatible measures/units; outliers; overlap; no causal claim from summaries. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Support each comparison with the relevant numerical or graphical evidence, justify the summary choice, and avoid interpreting greater spread as automatically greater center.

### Shifting and scaling data

**Diagnostic — ask and wait:** Shift every datum by7. What changes?

**Private diagnostic key:** center/location+7; spread unchanged.

**Teach in this order:** Transform an explicit dataset; derive center linearity; use absolute scale for spread; distinguish reflection from translation.

**Distinct worked model — reveal in steps:** Transform x=1,3,5 to y=−2x+4: y=2,−2,−6, mean −2, range 8 versus 4. SD and MAD double; order reverses. With multiplier 0 all data collapse and spread becomes 0.

**Misconception response and hint ladder:** If spread becomes negative, ask whether a distance has direction; next compare absolute pairwise separations.

**Practice progression:** Positive shift → positive scale → negative/zero affine transform. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Mean/median shifts; |scale| for spread; squared scale for variance; order reversal; zero scale. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Use the absolute scale factor for spread, include negative and zero factors, and interpret unit conversions consistently with the transformed data.

## Extended private calibration

**Prompt:** For population data 2,4,6 find mean and SD. Transform all values by $y=-2x+10$; compare center, spread and shape.

**Private worked key:** Mean 4, population variance $8/3$, SD $\sqrt{8/3}$. New data 6,2,-2 have mean 2 and SD $2\sqrt{8/3}$. Negative scaling reverses order; a shift alone preserves spread. With scale zero all values coincide and SD is zero. Sample SD of original data would be 2, a different convention.

This previously checked composite example can connect concepts after instruction. Split it into manageable turns; it does not replace the distinct diagnostic and worked model for each concept.

## Further task construction

Include skewed versus symmetric distribution comparisons, consistent units, sample/population conventions, negative/zero scaling and outlier sensitivity.

## Decision rehearsal and fading

**Choose the denominator from the data's role.** Treat $1,3,5$ as a complete population: mean 3, squared-deviation sum 8, variance $8/3$, SD $\sqrt{8/3}$. If these are a sample and the requested statistic is sample SD, use $8/(3-1)=4$ and $s=2$. The same values have different named summaries because the question changed.

For $y=-2x+10$, transformed values are $8,4,0$, mean 4 and population SD $2\sqrt{8/3}$; spread is multiplied by $|-2|$, not made negative. If the learner divides by 2 for a population, ask what population/sample role was stated, then offer the squared-deviation sum without its denominator. Fade to population $2,4,6$ (same SD) and let the learner obtain the matching technology output, recording the actual output and selected convention rather than claiming a tool run from the hand result.
