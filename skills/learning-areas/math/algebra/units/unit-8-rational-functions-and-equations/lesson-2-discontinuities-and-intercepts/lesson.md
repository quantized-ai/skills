# Lesson 8.2: Discontinuities and intercepts

Factored rational functions connect cancellation to discontinuities, intercepts, and signs. The original domain and the fully reduced expression together determine these features.

## Learning objectives

- Classify rational-function discontinuities using original exclusions and fully reduced factors.
- Determine intercepts and sign intervals while retaining every original domain exclusion.

## Learning outcome

Justify a consistent description of discontinuities, intercepts, and signs from the original domain and fully reduced expression.

## Proficiency criteria

- Record original denominator zeros and fully cancel common factors.
- Distinguish finite holes from vertical asymptotes and calculate hole coordinates.
- Find intercepts only at inputs in the original domain.
- For a nonzero function, partition the domain at zeros and exclusions and justify each interval sign; identify an identically zero function separately.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Holes and vertical asymptotes** | For a quotient of real polynomials with a denominator that is not identically zero, every real zero of the original denominator is excluded. After complete cancellation, an excluded input $c$ is a hole if the reduced denominator is nonzero there; its missing point is $(c,f_{\mathrm{red}}(c))$. If the reduced denominator still vanishes at $c$, $x=c$ is a vertical asymptote. Canceling one occurrence of a factor does not create a hole when another denominator occurrence remains. | Classify original excluded inputs as holes or vertical asymptotes after full reduction. Calculate hole coordinates and justify why cancellation does not always produce a hole. | Retain all original denominator exclusions after cancellation. Determine whether each excluded input has a finite missing value or unbounded nearby behavior. Calculate hole coordinates using the reduced formula and identify any denominator multiplicity that remains. |
| **Rational-function intercepts and signs** | An $x$-intercept is $(c,0)$ where the numerator is zero and $c$ belongs to the original domain. Canceled numerator zeros remain excluded. A $y$-intercept is $(0,f(0))$ only when zero is allowed. For a nonzero rational function, real zeros and original excluded inputs partition its domain into intervals on which its sign is constant. Factor signs or a test input determine each interval sign; passing a zero or exclusion need not change the sign. An identically zero function has output zero at every allowed input, all of which give $x$-intercepts. | Find rational-function intercepts while retaining original domain exclusions, including canceled numerator zeros. Determine and justify signs on intervals separated by zeros and original excluded inputs, handling an identically zero function separately. | Accept numerator zeros only at allowed inputs and evaluate the function at zero only when defined. For a nonzero function, partition the domain at every zero and exclusion and justify each interval sign without assuming every boundary changes it. Recognize when all allowed outputs are zero. |
