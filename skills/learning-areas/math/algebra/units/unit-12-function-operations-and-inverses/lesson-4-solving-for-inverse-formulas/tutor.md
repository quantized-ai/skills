## Reasoning activity

Use after the relevant basic procedure is accessible. Reveal the prompt first, let the student identify and repair the reasoning, and close with the correct explanation. In assess mode generate a new task instead of administering this exposed example.

**Prompt:** Does (3x+6)/(x+2), x≠−2, have an inverse function on its natural domain?

**Private reasoning key:** It equals 3 at every allowed input, so many inputs have the same output. Its inverse relation is not a function; cancellation does not make the original domain a singleton.

Ask what changed between the original claim and the repaired explanation. If the response is only a guessed answer, use the corresponding concept’s targeted cue below; after feedback, collect a new independent attempt.

## Concept guidance

### Linear inverses and reversal of operations

Curriculum reference: **Linear inverses and reversal of operations** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Invert f(x)=3x-7 on all real inputs.

**Agent key:** Solving y=3x-7 gives x=(y+7)/3, so the inverse is $(x+7)/3$, domain and range all real.

**Worked example:** Restrict f(x)=2x+1 to x≥3. State the inverse and both sets.

**Worked reasoning:** Inverse $(x-1)/2$ has domain [7,∞) and range [3,∞); the inherited restrictions matter.


#### Teaching sequence

In y=mx+b with m≠0, subtract b and then divide by m to recover the original input. Relabel this expression as the inverse rule and exchange the actual domain and range, including restrictions and endpoint direction for negative m. Verify that the inverse composition returns every allowed input, not just one numerical example.

#### Respond to student reasoning

**First hint:** Which operation must be undone first?

If inverse operations occur in the same order as original ones, trace a value through both. If m=0 is divided by, classify the constant rule. If the original domain is restricted, compute its image before declaring an all-real inverse domain.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Begin with all-real linear rules, then positive/negative slopes and restricted intervals. Compare inverse and reciprocal and ask for an operation-order explanation.

#### Assessment evidence

Require nonzero slope, solved inverse, exact exchanged sets and composition verification. Restriction boundaries belong to the inverse domain only when attained originally.

Use the [fresh-question policy](../question-generation.md); the two calibration examples above are exposed learning material, not the default quiz. Collect the curriculum's full proficiency evidence, retain demonstrated components, and reassess unresolved cases with new tasks.

### Simple rational inverses

Curriculum reference: **Simple rational inverses** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Invert $f(x)=(x+1)/(x-2)$.

**Agent key:** Solve $yx-2y=x+1$: inverse $(2x+1)/(x-1)$, excluding x=1. Original domain excludes 2 and range excludes 1.

**Worked example:** Does $f(x)=(2x+2)/(x+1)$ have an inverse on its natural domain?

**Worked reasoning:** No. It is constant 2 for x≠-1; the determinant is zero and many inputs share its output.


#### Teaching sequence

For (ax+b)/(cx+d), verify nonconstancy using ad−bc≠0 within the stated family and record original denominator exclusions. Set y equal to the rule, multiply on the allowed domain, collect terms containing x and factor x before dividing. Derive the inverse's forbidden denominator input and show it equals an excluded original output; state all four sets.

#### Respond to student reasoning

**First hint:** Is the fractional-linear formula nonconstant before solving?

If ad−bc=0 is ignored, simplify to expose a constant rule with many preimages. If x terms are divided separately, collect them first. If a canceled original denominator root is restored, revisit the original function definition.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Use nonconstant examples, constant degeneracies and verification of both excluded values. Include complete set exchange rather than formula-only answers.

#### Assessment evidence

Assess nonconstancy, legal equation steps, inverse formula, original/inverse domain and range, and the reason for each exclusion. Handle c=0 as a linear special case when permitted.
