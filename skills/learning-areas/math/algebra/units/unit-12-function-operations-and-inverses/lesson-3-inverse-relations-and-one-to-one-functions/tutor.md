**Prompt:** A complete function table contains (−1,4),(2,4),(3,7). Does its inverse define a function?

**Private reasoning key:** No. Reversal assigns both −1 and 2 to input 4. The original remains a valid function, but is not one-to-one.

## Concept guidance

### When an inverse is a function

Curriculum reference: **When an inverse is a function** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Does f(x)=x² on all real x have an inverse function?

**Agent key:** No: f(2)=f(-2)=4, so swapping inputs and outputs gives two outputs for input 4.

**Worked example:** Compare inverse and reciprocal for f(x)=2x+3.

**Worked reasoning:** The inverse is $(x-3)/2$; the reciprocal is $1/(2x+3)$ and has a different domain and meaning.


#### Teaching sequence

An inverse relation reverses input-output pairs. It is a function exactly when each original output comes from one original input. Use a horizontal-line argument or an explicit collision of distinct inputs to test this; a non-one-to-one original may still be a valid function. Contrast undoing f with taking 1/f, which changes outputs arithmetically and has different restrictions.

#### Respond to student reasoning

**First hint:** Would one output identify a unique original input?

If the vertical-line test is used for inverse existence, reverse a pair collision to see the multiple inverse outputs. If f⁻¹ is read as a reciprocal, compare the two operations on a simple linear rule.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Classify complete relations, tables and formulas, justify one-to-one behavior or supply a collision, and distinguish inverse/reciprocal evaluations.

#### Assessment evidence

Require a valid one-to-one argument or counterexample, relation-versus-function distinction and the inverse's domain as the original range.

Use the [fresh-question policy](../question-generation.md); the two calibration examples above are exposed learning material, not the default quiz. Collect the curriculum's full proficiency evidence, retain demonstrated components, and reassess unresolved cases with new tasks.

### Inverse values from tables and graphs

Curriculum reference: **Inverse values from tables and graphs** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** A complete one-to-one table has pairs (1,4),(2,7),(5,9). Find inverse values and domain.

**Agent key:** Swapped pairs are (4,1),(7,2),(9,5); inverse domain is {4,7,9}.

**Worked example:** If an original graph has a closed endpoint at (2,5) and an open endpoint at (4,8), what happens under inversion?

**Worked reasoning:** Reflection gives a closed endpoint at (5,2) and open endpoint at (8,4); swapping coordinates preserves inclusion.


#### Teaching sequence

Locate an original pair (a,b) before stating f⁻¹(b)=a. Reverse every pair in a complete table and exchange the full domain/range sets. In a graph, reflect across y=x, preserving open or closed status and any exclusions. A sample table only supports inverse values for known pairs unless a full rule or domain supplies more.

#### Respond to student reasoning

**First hint:** Which original set becomes the inverse input set?

If coordinates are negated rather than swapped, compare distances from the diagonal. If a missing value is interpolated without permission, state what the table actually establishes. If an open endpoint becomes closed, track membership attached to its pair.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Use finite complete tables, explicitly sampled data, endpoints and labelled graph features. Ask for both numerical inverse values and set exchange.

#### Assessment evidence

Assess correct pair reversal, finite membership, endpoint inclusion, domain/range exchange and evidence limits. First confirm the inverse is a function if that claim is required.

## Decision model and graduated practice

The complete table $(1,4),(2,7),(5,9)$ is one-to-one because its three outputs are distinct. Swap pairs to obtain $(4,1),(7,2),(9,5)$; inverse domain is exactly $\{4,7,9\}$, not the interval between them. In contrast, adding $(6,7)$ to the original creates two inverse outputs for input $7$, although the original remains a function.

Cue “Would this output identify one original input?”; next write the reversed pairs sharing input $7$; then identify one resulting output, leaving the conflict explanation. Fade by asking for a valid added original pair and one that breaks one-to-one behavior. For $f(x)=2x+3$, inverse $(x-3)/2$ undoes operations; reciprocal $1/(2x+3)$ divides by an output. Their different formulas and domains answer different operations.
