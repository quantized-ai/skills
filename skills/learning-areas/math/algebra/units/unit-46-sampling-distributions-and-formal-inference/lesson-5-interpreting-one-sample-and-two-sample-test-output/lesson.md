# Lesson 46.5: Interpreting one-sample and two-sample test output

Technology-generated inference requires checking parameters, sample structure, method conditions, and the reported comparison.

## Learning objectives

- Interpret technology-generated large-sample tests for a proportion, a mean, two proportions, and two independent means.
- Describe possible Type I and Type II errors and compare their contextual consequences and relation to power.

## Proficiency criteria

- Match output to the parameter, tail rule, null model, and z or t procedure; verify sampling independence, null expected counts for proportions, or normal/large-sample mean conditions; interpret the statistic, p-value, ordered effect, and contextual conclusion without treating a software result as proof that assumptions hold.
- State each error using the population claim, distinguish a possible error from a known error after a test, and avoid interpreting significance level as the probability this particular rejection is wrong.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Large-sample test families** | One-proportion and one-mean tests address one parameter; two-proportion and independent two-mean tests address an ordered difference. Proportion z tests require random independent binary observations and adequate null expected successes and failures (at least 10 of each per group is the convention here); a two-proportion equality test uses the pooled null proportion. Mean z output assumes known population standard deviation; one-sample t and Welch independent-means t output estimate it. Mean procedures require normal populations or justified large-sample approximations with finite variance and no dominating extremes. Negligible sampling fractions justify approximate independence without replacement. Paired observations require a paired procedure, outside this independent-means scope. | Interpret technology-generated large-sample tests for a proportion, a mean, two proportions, and two independent means. | Match output to the parameter, tail rule, null model, and z or t procedure; verify sampling independence, null expected counts for proportions, or normal/large-sample mean conditions; interpret the statistic, p-value, ordered effect, and contextual conclusion without treating a software result as proof that assumptions hold. |
| **Type I and Type II errors** | A Type I error rejects a true null; a Type II error fails to reject a false null. Their consequences depend on context. Power is one minus Type II error probability for a specified alternative and depends on effect size, sample size, variability, and significance level. | Describe possible Type I and Type II errors and compare their contextual consequences and relation to power. | State each error using the population claim, distinguish a possible error from a known error after a test, and avoid interpreting significance level as the probability this particular rejection is wrong. |
