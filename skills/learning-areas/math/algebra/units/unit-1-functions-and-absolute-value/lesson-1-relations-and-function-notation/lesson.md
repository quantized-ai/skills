# Lesson 1.1: Relations and function notation

Relations establish which inputs are allowed and whether each has a unique output. Function notation then connects these assignments to formulas and to quantities in context.

## Learning objectives

- Classify relations and identify their domain and range.
- Evaluate function notation and interpret quantities, units, and domain conditions.

## Learning outcome

By the end of this lesson, you should be able to decide whether a relation defines a function and use its notation to compute and communicate outputs.

## Proficiency criteria

- Justify a function classification with the single-output condition across ordered pairs, tables, and graphs; repeated outputs alone must not be treated as a violation.
- Distinguish domain from range and identify exactly the members of each finite set.
- Substitute a complete numerical or algebraic input into every occurrence of the variable while preserving grouping and signs.
- Interpret an input-output statement with the correct quantities and units, without treating the function name as a multiplier.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Functions as single-output relations** | A relation pairs inputs with outputs. Identical repeated pairs do not introduce conflicting outputs. A function assigns exactly one output to every input in its domain; different inputs may share an output. The domain is the set of inputs and the range the set of attained outputs. A graph represents a function of its horizontal coordinate exactly when every vertical line meets it at most once. | Classify a relation given by ordered pairs, a table, or a graph using the single-output condition and explain the vertical-line test. List the distinct domain and range elements of a finite relation. | Justify classification for each representation and identify any input with conflicting outputs. Allow repeated outputs; do not require an output for inputs outside the domain. Identify exactly the domain and range members without inserting intermediate values; redundant repeated entries do not change set membership. |
| **Evaluating and interpreting function notation** | In $f(x)$, $f$ names a function and the parenthesized expression supplies its complete input; the notation is not multiplication. Evaluation substitutes that input into every occurrence of the variable, preserving grouping and signs. Inputs must belong to the stated domain. In context, input and output have distinct meanings and their own units. | Evaluate and simplify a formula at numerical and algebraic inputs allowed by its domain. Interpret function-notation statements using the quantities, units, and domain conditions in context. | Substitute the complete input consistently, retaining needed parentheses. Evaluate or simplify correctly within the stated domain. Identify the input and output quantities with their units and contextual restrictions. |
