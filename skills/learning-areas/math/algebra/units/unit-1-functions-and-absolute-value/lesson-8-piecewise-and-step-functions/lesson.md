# Lesson 1.8: Piecewise and step functions

Piecewise definitions assign formulas to input regions; step functions assign constant outputs to such regions. Boundary membership determines both evaluation and graph markers.

## Learning objectives

- Evaluate and graph piecewise rules, verify consistency of overlapping branches, and determine domain and range.
- Evaluate floor functions and construct step functions from threshold conditions with correct boundary membership.

## Learning outcome

By the end of this lesson, you should be able to move between a piecewise rule, its graph, and threshold conditions without ambiguity at boundaries.

## Proficiency criteria

- Select the branch using its input condition before evaluating the output, including at jump points and negative inputs.
- Verify that overlapping branch conditions assign consistent outputs.
- Draw each branch only on its permitted region and mark included and excluded endpoints consistently with evaluation.
- Combine branch domains and attained outputs to form the whole domain and range without filling gaps.
- Construct a threshold-based constant rule with complete, compatible branch conditions and distinguish floor evaluation from truncation toward zero.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Evaluating and graphing piecewise functions** | A piecewise rule assigns a formula to each specified input region. Branch conditions determine which formula applies and which endpoints are included. A closed graph point is an attained value; an open endpoint excludes that branch’s boundary value. Each branch domain is its stated input region intersected with the inputs on which its formula is defined. The whole domain is the union of branch domains and the range the union of attained branch outputs. Overlapping conditions define a function only when all applicable formulas agree at every shared input. | Evaluate piecewise rules from their branch conditions and determine whether overlapping conditions assign consistent outputs. Graph piecewise branches with correct endpoint conventions and determine the complete domain and range. | Check input membership before evaluating a branch. Identify conflicting outputs in overlaps and permit overlaps whose outputs agree. Plot each formula only on its allowed region with correct open and closed markers. Combine branch input and output sets without filling gaps or discarding a value attained elsewhere. |
| **Step functions and endpoint conventions** | A step function has constant outputs on specified intervals with endpoint membership determined by its rule. The floor function $\lfloor x\rfloor$ is the greatest integer at most $x$; for integer $n$ it equals $n$ on $[n,n+1)$. Floor is not truncation toward zero. Threshold conditions determine constant branches; their intervals must cover the intended domain without conflicting outputs. The range contains the attained step values, not intervals joining them. | Graph and evaluate step functions, including floor, at negative inputs and jump points, and determine their domain and range. Construct piecewise constant functions from threshold conditions with complete, compatible branch intervals. | Select the correct constant branch at negative inputs and jump boundaries. Apply the floor definition correctly for negative noninteger inputs. Translate thresholds into strict or inclusive endpoints without gaps in the intended domain or conflicting overlaps. Graph the rule and state exactly its domain and attained step values. |
