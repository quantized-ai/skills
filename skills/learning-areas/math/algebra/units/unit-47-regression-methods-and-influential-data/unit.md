# Unit 47: Regression methods and influential data

Alternative fitting criteria and influence analysis explain why different lines summarize the same observations differently.

## Main learning objectives

- Construct candidate linear fits by transforming the parent function and compare squared-error and absolute-error criteria.
- Use graphical technology to investigate leverage, outliers, and the influence of observations on a fitted line.

## Concepts and topics

Transformed lines and absolute versus squared error; Median-median fitting; Outliers and influential observations; Contextual coefficients and unexplained variation.

## Lessons

- [47.1: Comparing fitting criteria](lesson-1-comparing-fitting-criteria/lesson.md) — A fitted line depends on a defined error criterion, which determines how residual size affects the result.
- [47.2: Influence, residual variation, and model interpretation](lesson-2-influence-residual-variation-and-model-interpretation/lesson.md) — Extreme inputs and unusual responses have different effects on fitted models and predictions.
