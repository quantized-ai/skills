## Reasoning and error-analysis activity

**Ask:** Because √25 contains a radical, a student calls it irrational. Ask the student to locate the first invalid inference, repair the reasoning, and explain a check or counterexample.

**Private reasoning and response:** √25=5 is an integer and rational. Ask for the expression's value, then contrast √2; classification concerns values rather than symbols.

If the student gives only a corrected answer, ask why the original method failed. If the reason is secure, request a different example where the distinction matters. If they remain stuck, use the targeted response below for the relevant concept and mark the attempt assisted.

## Concept teaching plans

### Real-number classifications

**Diagnostic — ask and wait:** Classify −7,0,√9,√2 as integer/rational/irrational.

**Private diagnostic key:** first three integers and rational; √2 irrational.

**Teach in this order:** Build nested number sets using examples; reduce representations before classification; state the convention for whether 0 is natural.

**Distinct worked model — reveal in steps:** $0.\overline{27}=27/99=3/11$ is rational though not terminating; √16=4 is natural/integer/rational. Classification follows the value, not its written radical or decimal appearance.

**Misconception response and hint ladder:** If every radical is called irrational, ask for √16's value; then contrast it with √2.

**Practice progression:** Classify familiar values → classify equivalent forms → justify a non-example or boundary convention. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Nested membership; integers/rationals; terminating/repeating decimals; irrational examples; natural-number convention. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** List every applicable number set; do not infer irrationality from a finite displayed decimal or confuse a rational approximation with the exact number.

### Order and number-line location

**Diagnostic — ask and wait:** Order −3/2,−1.4,−√2.

**Private diagnostic key:** −1.5<−√2<−1.4.

**Teach in this order:** Compare common exact representations or justified bounds; place larger values to the right; preserve sign when translating positive estimates.

**Distinct worked model — reveal in steps:** Since 1.7²=2.89<3<3.24=1.8², 1.7<√3<1.8. Negating reverses order: −1.8<−√3<−1.7. Locate it within that interval on a labeled number line.

**Misconception response and hint ladder:** If −1.8 is larger than −1.7, ask which is farther left; next compare each distance from 0.

**Practice progression:** Rational ordering → irrational bounds → mixed exact order without premature rounding. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Negative order; common denominator/decimal comparison; labeled number line; justified irrational bounds. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Compare negative values correctly, preserve inequality direction in numerical comparisons, and distinguish exact rational locations from bounded irrational locations.

### Absolute value and numerical distance

**Diagnostic — ask and wait:** What is the distance from −4 to3?

**Private diagnostic key:** |3−(−4)|=7.

**Teach in this order:** Identify reference point; form a difference; take absolute value; show both directions when reconstructing positions.

**Distinct worked model — reveal in steps:** Solve |x−2|=5 by locating points five units from 2: x=−3 or7. Both satisfy the distance condition; |−3−2|=5 and |7−2|=5. Absolute value is a nonnegative distance, not simply deleting any minus sign inside an expression.

**Misconception response and hint ladder:** If |a−b| is replaced by |a|−|b|, test a=−4,b=3; next draw the interval crossing 0.

**Practice progression:** Distance from 0 → distance between points → reconstruct points from a distance. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Nonnegative distance; signed location versus magnitude; subtraction inside bars; symmetric point cases. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** State the reference represented by zero; report nonnegative distances with correct units and preserve signs when comparing values.

## Extended private calibration

**Prompt:** Classify $-3$, $0.125$, $\sqrt2$, and $\sqrt9$ in the real number system; order $-1.4,-7/5,-\sqrt2$ and find the distance from -3 to 5.

**Private worked key:** $-3$ is integer and rational; $0.125=1/8$ is rational; $\sqrt2$ is irrational; $\sqrt9=3$ is natural, whole, integer and rational. $-\sqrt2<-1.4=-7/5$. Distance is $|5-(-3)|=8$. State the adopted natural-number convention if zero is involved.

This previously checked composite example can connect concepts after instruction. Split it into manageable turns; it does not replace the distinct diagnostic and worked model for each concept.

## Further task construction

Mix overlapping classifications, equivalent representations, negative order and distance; distinguish an exact irrational value from a rounded decimal.

## Decision rehearsal and fading

**Choose the comparison before calculating.** On a vertical number line measured in meters relative to sea level, compare $-\sqrt5$ and $-2.2$. Since $2.2^2=4.84<5<5.29=2.3^2$, negation gives $-2.3<-\sqrt5<-2.2$. Thus $-\sqrt5$ has the lower elevation but the greater distance from zero. The exact terminating decimal $-2.2=-11/5$ is rational; it is not an exact replacement for the radical.

**Respond to the observed step.** If the learner writes $-\sqrt5>-2.2$ because $\sqrt5>2.2$, ask “What happens to left and right when both points are reflected across zero?” Next supply the positive bounds; finally supply $-2.3<-\sqrt5$ and ask them to finish the chain. If only an answer is shown, first request the comparison they used. Fade to locating $-\sqrt6$ between consecutive tenths (key: $-2.5<-\sqrt6<-2.4$), with the learner choosing the squares and explaining value versus magnitude.
