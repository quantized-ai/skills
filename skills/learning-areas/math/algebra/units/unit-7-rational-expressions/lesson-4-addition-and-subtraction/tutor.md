## Reasoning activity

Use after the relevant basic procedure is accessible. Reveal the prompt first, let the student identify and repair the reasoning, and close with the correct explanation. In assess mode generate a new task instead of administering this exposed example.

**Prompt:** Repair 1/(x−1)+1/(x+1)=2/(2x).

**Private reasoning key:** The LCD is (x−1)(x+1); the numerator is (x+1)+(x−1)=2x. The sum is 2x/(x²−1), with x≠±1.

Ask what changed between the original claim and the repaired explanation. If the response is only a guessed answer, use the corresponding concept’s targeted cue below; after feedback, collect a new independent attempt.

## Concept guidance

### Common denominators

Curriculum reference: **Common denominators** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Simplify $x/(x-2)-(3x-4)/(x-2)$.

**Agent key:** Numerator $x-3x+4=-2(x-2)$ gives $-2$ for $x\ne2$.

**Worked example:** Why is $1/x+2/x$ not $3/(2x)$?

**Worked reasoning:** The common denominator remains x; addition combines numerators, giving $3/x$ for $x\ne0$.


#### Teaching sequence

Once a common denominator is established, combine entire numerators while keeping that denominator. For subtraction, distribute the minus through every term in the second numerator before collecting and factoring. A constant reduced result still inherits denominator exclusions. Relate this to equal-sized fractional units without adding denominators.

#### Respond to student reasoning

**First hint:** Does the subtraction act on the complete second numerator?

If denominators are added, compare 1/5+2/5 with the proposed 3/10. If a subtraction changes only its first numerator term, put parentheses around the subtrahend. If cancellation precedes collection, identify whether the canceled object is a factor.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Use addition, subtraction, numerator cancellation and zero/constant results. Reverse the problem by supplying a difference and asking for one missing numerator under stated restrictions.

#### Assessment evidence

Assess common-denominator reasoning, full signed numerator combination, valid reduction and retained exclusions. Correct arithmetic alone does not excuse a lost domain condition.

### Least common denominators

Curriculum reference: **Least common denominators** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Add $1/(x-1)+2/(x+1)$.

**Agent key:** Common denominator $(x-1)(x+1)$ gives numerator $x+1+2x-2=3x-1$; exclude $\pm1$.

**Worked example:** Find an LCD for $1/[2x(x-1)]$ and $1/[3(x-1)^2]$.

**Worked reasoning:** $6x(x-1)^2$: coefficient LCM is 6 and each factor uses its largest multiplicity. Exclude 0 and 1.


#### Teaching sequence

Factor denominators, choose an LCD containing each irreducible factor to its greatest needed multiplicity, and handle integer coefficient LCMs when using that convention. Multiply each numerator by exactly its missing factors. Combine, factor and reduce only after the fractions share the denominator. Record exclusions from the original denominators independently of the LCD's presentation.

#### Respond to student reasoning

**First hint:** Which factors and multiplicities are missing from each denominator?

If every denominator is multiplied together unnecessarily, compare factor multiplicities and show a smaller valid common denominator. If a numerator is unchanged during scaling, ask which factor of one was applied. If cancellation crosses a sum, factor the complete numerator first.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Start with coprime linear denominators, then shared factors, repeated powers and numerical coefficients. Include subtraction and a reducible combined result.

#### Assessment evidence

Require a justified common denominator, equivalent numerator scaling, signed combination, simplification and all restrictions. Accept a valid nonleast common denominator unless leastness itself is assessed.
