## Reasoning and error-analysis activity

**Ask:** Two equations with the same slope and intercept are called distinct parallel lines. Ask the student to locate the first invalid inference, repair the reasoning, and explain a check or counterexample.

**Private reasoning and response:** They define the same line. Ask whether any point belongs to one but not the other; compare distinct parallel and horizontal/vertical perpendicular examples.

If the student gives only a corrected answer, ask why the original method failed. If the reason is secure, request a different example where the distinction matters. If they remain stuck, use the targeted response below for the relevant concept and mark the attempt assisted.

## Concept teaching plans

### Parallel lines

**Diagnostic — ask and wait:** Are y=2x+1 and y=2x−4 parallel?

**Private diagnostic key:** yes, distinct equal-slope lines.

**Teach in this order:** Compare directions through slopes or verticality; distinguish coincident from distinct; use a point to determine the new offset.

**Distinct worked model — reveal in steps:** The line parallel to3x−2y=8 through (0,5) has slope 3/2, so y=(3/2)x+5. The same slope and same intercept would instead be the same line. Distinct vertical lines are also parallel.

**Misconception response and hint ladder:** If equal slopes alone prove distinct parallelism, ask whether the intercepts also agree; next compare equations fully. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Recognize parallel lines → construct through a point → vertical/coincident cases. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Equal finite slopes and distinctness; vertical pair; equation verification; contextual units if relevant. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Check both slope and intercept or standard-form equivalence, handle vertical lines, and state when the prescribed point forces the same line rather than a distinct parallel.

### Perpendicular lines

**Diagnostic — ask and wait:** What slope is perpendicular to2/3?

**Private diagnostic key:** −3/2.

**Teach in this order:** Relate a direction vector (a,b) to its quarter-turn (−b,a); derive the slope relation; handle horizontal/vertical separately.

**Distinct worked model — reveal in steps:** A perpendicular through (2,1) to y=−2x+4 has slope 1/2, giving y−1=(1/2)(x−2), hence y=x/2. Horizontal and vertical lines form a perpendicular pair; the negative-reciprocal calculation does not apply to undefined slope.

**Misconception response and hint ladder:** If only the sign changes, ask whether products of slopes equal −1; next compare 2/3 and −2/3. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Recognize slope pairs → construct a line → horizontal/vertical and geometric explanation. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Negative reciprocal; finite nonzero condition; product −1; exceptions; original point check. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Use a negative reciprocal rather than a sign change alone, handle zero and undefined slopes separately, and verify both point membership and perpendicular direction.

## Extended private calibration

**Prompt:** Through $(3,-1)$, find a line parallel and a line perpendicular to $y=2x+5$. Then handle a line perpendicular to $x=4$.

**Private worked key:** Parallel line $y+1=2(x-3)$, hence $y=2x-7$; perpendicular line $y+1=-\tfrac12(x-3)$, hence $y=-x/2+1/2$. A line through $(3,-1)$ perpendicular to vertical $x=4$ is horizontal $y=-1$.

This previously checked composite example can connect concepts after instruction. Split it into manageable turns; it does not replace the distinct diagnostic and worked model for each concept.
