## Reasoning and error-analysis activity

**Ask:** A line through (−2,1) is written y−1=m(x−2). Ask the student to locate the first invalid inference, repair the reasoning, and explain a check or counterexample.

**Private reasoning and response:** The anchored horizontal difference isx −(−2)=x+2. Substituting the given point should make both differences 0; use that check before expanding.

If the student gives only a corrected answer, ask why the original method failed. If the reason is secure, request a different example where the distinction matters. If they remain stuck, use the targeted response below for the relevant concept and mark the attempt assisted.

## Concept teaching plans

### Point-slope and two-point construction

**Diagnostic — ask and wait:** Write the line through (2,1) with slope −3.

**Private diagnostic key:** y−1=−3(x−2).

**Teach in this order:** Calculate slope if needed; anchor changes at the given point; retain parentheses; check both data points.

**Distinct worked model — reveal in steps:** Through (−1,2),(3,4), slope 2/4=1/2, so y−2=(1/2)(x+1), or y=(1/2)x+5/2. Both original points verify it. For equal x-coordinates use x=c rather than a finite slope formula.

**Misconception response and hint ladder:** If x−(−1) becomes x−1, ask what horizontal change is zero at x=−1; next substitute that anchor. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Point+slope → two points → vertical/horizontal lines. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Correct anchor signs; distinct points; vertical case; equivalent forms; original checks. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Use both coordinate differences consistently, distinguish distinct from coincident points, and verify all supplied geometric information.

### Equivalent line forms and multiple representations

**Diagnostic — ask and wait:** Are y=2x−3 and 2x−y=3 the same line?

**Private diagnostic key:** yes.

**Teach in this order:** Transform with nonzero scaling and equality operations; extract intercepts/slope; use a table or graph to cross-check structural equivalence.

**Distinct worked model — reveal in steps:** Starting with x/2+y/3=1, multiply 6 to get 3x+2y=6, then y=−1.5x+3. Intercepts (2,0),(0,3) agree in each form; different forms expose different features.

**Misconception response and hint ladder:** If changing form changes the line, ask whether each step preserved solutions; next substitute one known pair into both forms. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Convert forms → match table/graph/equation → choose useful form. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Standard/point-slope/slope-intercept as appropriate; same solution set; meaningful form selection; vertical exception. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Respect coefficients that preclude a chosen form, retain the original solution set, and verify the constructed equation against every supplied point or condition.

## Extended private calibration

**Prompt:** Find the line through $(2,1)$ and $(5,7)$ in point-slope, slope-intercept and standard form. Also handle $(2,1)$ and $(2,7)$.

**Private worked key:** First slope 2, so $y-1=2(x-2)$, $y=2x-3$, and $2x-y=3$ are equivalent. Substitution verifies both points. Second is $x=2$, not a slope-intercept function y of x.

This previously checked composite example can connect concepts after instruction. Split it into manageable turns; it does not replace the distinct diagnostic and worked model for each concept.
