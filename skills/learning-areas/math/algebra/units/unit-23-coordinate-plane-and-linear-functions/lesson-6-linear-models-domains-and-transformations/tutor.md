## Concept teaching plans

### Linear model construction and interpretation

**Diagnostic — ask and wait:** A taxi costs 5 plus 2 per km. Equation/domain?

**Private diagnostic key:** C=5+2d,d≥0.

**Teach in this order:** Define variables/units; identify fixed level and rate; build equation; infer physically meaningful domain and evaluate within it.

**Distinct worked model — reveal in steps:** A tank contains 50 L and drains 4 L/min: V=50−4t, with 0≤t≤12.5 before empty. Although the line extends mathematically, negative volumes beyond 12.5 are outside this model.

**Misconception response and hint ladder:** If intercept and rate are swapped, ask what is paid/contained at zero input; next calculate one-unit change.

**Practice progression:** Direct model → infer from two observations → domain-limited prediction. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Units; rate/intercept; feasible domain; extrapolation limitation; contextual verification. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Define quantities and units, separate mathematical from reasonable contextual domains, state continuous or discrete restrictions, and explain the meaning or contextual irrelevance of an intercept.

### Transformations of linear functions

**Diagnostic — ask and wait:** For f(x)=2x+1, expand f(x−3).

**Private diagnostic key:** 2x−5, a3-unit right shift.

**Teach in this order:** Apply changes to inputs before outputs; use a mapped point to check signs; compare symbolic and geometric descriptions.

**Distinct worked model — reveal in steps:** Let g(x)=−2f(x+1)+4. Substitute to get −2(2x+3)+4=−4x−2. Point (0,1) on f maps to(−1,2) on g; the coordinate rule verifies the horizontal/vertical transformations together.

**Misconception response and hint ladder:** If x+1 is called a right shift, ask which new input makes the old input 0; next solve x+1=0.

**Practice progression:** Single shift → reflection/scale → combined transformation and slope/intercept check. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Input/output distinction; horizontal sign; slope changes; coordinate validation; coincident effects for linear graphs acknowledged. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Track point coordinates and the domain, distinguish horizontal from vertical rules despite coincident final lines, and handle negative or zero factors explicitly.

## Extended private calibration

**Prompt:** A tank starts at 24 liters and drains at 3 liters/minute until empty. Build a model and domain. For $f(t)=24-3t$ on $[0,8]$, find $g(t)=f(t-2)+5$ and its inherited domain.

**Private worked key:** $V=24-3t$ for $0\le t\le8$; zero at 8 minutes. $g=35-3t$ with $t-2\in[0,8]$, so domain $[2,10]$. It is the shifted mathematical function; it is not automatically the original tank's physical process.

This previously checked composite example can connect concepts after instruction. Split it into manageable turns; it does not replace the distinct diagnostic and worked model for each concept.

## Additional worked coverage

For f(t)=24−3t on [0,8], −f(t) reflects outputs but preserves the input domain; f(−t) has domain [−8,0]. The rule 0·f(t) is zero only on the original domain [0,8]. In contrast f(0·t)=f(0)=24 is defined for all real t when no external restriction applies, because 0 is in f's domain. If 0 were excluded from the domain, f(0·t) would be undefined everywhere. This separates a zero output multiplier from a zero input multiplier.

Use this reasoning as instruction or private calibration. Generate a fresh independent counterpart after exposure; this is not a fixed reassessment task.

## Decision rehearsal and fading

**Transform the permitted inputs with the rule.** Let $f(x)=2x+1$ on $[0,3]$ and $g(x)=f(x-2)-4$. The old input $u=x-2$ must satisfy $0\le u\le3$, so $2\le x\le5$. Algebra gives $g(x)=2x-7$. A point $(u,v)$ on $f$ maps to $(u+2,v-4)$; the endpoints become $(2,-3)$ and $(5,3)$.

If the equation is correct but the old domain is retained, cue “Which new inputs keep the inside input in $[0,3]$?” Next give $0\le x-2\le3$; work its left inequality and leave the right. Fade to $h(x)=f(x+1)+2$ with no domain setup (key $2x+5$ on $[-1,2]$). Have the learner graph both restricted functions using available technology and inspect the actual display; an equation and mapped endpoints alone do not establish the required technology execution.
