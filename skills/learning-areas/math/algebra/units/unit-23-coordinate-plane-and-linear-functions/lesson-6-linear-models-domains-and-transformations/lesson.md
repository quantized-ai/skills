# Lesson 23.6: Linear models, domains, and transformations

Linear functions describe constant-rate relationships whose parameters, domains, and transformed graphs must be interpreted together.

## Learning objectives

- Build and compare linear models with meaningful domains, ranges, and parameter units.
- Describe graph changes under input and output transformations of linear functions.

## Proficiency criteria

- Differentiate proportional relationships from linear relationships with initial offsets.
- Preserve contextual restrictions and explain which transformations produce identical linear graphs.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Linear model construction and interpretation** | A constant-rate model has form \(f(x)=mx+b\), with \(m\) carrying output units per input unit and \(b\) representing the output at input zero when meaningful. A context may have a continuous interval or discrete inputs; the range consists of the resulting permitted outputs. Equal output differences over equal input intervals follow from \(f(x+h)-f(x)=mh\). | Construct and compare linear models from multiple representations, justify constant differences, and interpret their parameters, domains, and ranges. | Define quantities and units, separate mathematical from reasonable contextual domains, state continuous or discrete restrictions, and explain the meaning or contextual irrelevance of an intercept. |
| **Transformations of linear functions** | For a linear function \(f\), \(af(x)\) scales outputs, \(f(x)+d\) translates vertically, \(f(x-c)\) translates horizontally, and \(f(bx)\) scales inputs with reciprocal horizontal scale when \(b\ne0\), including reflections for negative factors. For the parent \(f(x)=x\), input and output scaling produce the same equation; horizontal and vertical translations can also produce identical lines. Zero factors may collapse a graph. | Determine and explain transformations of linear graphs under input and output changes and verify the effects algebraically and graphically with technology. | Track point coordinates and the domain, distinguish horizontal from vertical rules despite coincident final lines, and handle negative or zero factors explicitly. |
