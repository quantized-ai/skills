## Reasoning activity

Use after the relevant basic procedure is accessible. Reveal the prompt first, let the student identify and repair the reasoning, and close with the correct explanation. In assess mode generate a new task instead of administering this exposed example.

**Prompt:** A graph for y=−(x−1)²+4 passes through (0,3) and (2,3) but opens upward. Can the two correct points certify it?

**Private reasoning key:** No. The equal-height points confirm one symmetry pair, but the negative leading coefficient requires downward opening and a maximum at (1,4). Verification must include all defining features.

Ask what changed between the original claim and the repaired explanation. If the response is only a guessed answer, use the corresponding concept’s targeted cue below; after feedback, collect a new independent attempt.

## Concept guidance

### Transformations of a quadratic parent function

Curriculum reference: **Transformations of a quadratic parent function** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Map $(2,4)$ on $y=x^2$ to $y=-2(x-1)^2+3$.

**Agent key:** Translate the input right 1 and transform output by $-2v+3$: $(3,-5)$.

**Worked example:** Can the graph of $a(bx)^2$ identify $a$ and $b$ separately?

**Worked reasoning:** Generally no: it determines only $ab^2$. For instance $a=4,b=1$ and $a=1,b=2$ give the same graph.


#### Teaching sequence

Use point correspondence: a parent input u occurs when the new inside expression equals u, and transform the parent output separately. For x² the horizontal reflection is concealed by evenness, and inside scale b appears as b² in the expanded coefficient. Demonstrate why different a,b pairs can give the same graph before asking for parameter recovery.

#### Respond to student reasoning

**First hint:** Which new input reproduces the old parent input?

If horizontal coordinates are multiplied rather than solved for, substitute the proposed new input into the inside expression. If a unique a,b is inferred from one quadratic coefficient, show two pairs with the same ab².

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Begin with one translation or scale, then combined signed operations and matching points. Include a symmetric parent that hides reflection and data insufficient to identify all parameters.

#### Assessment evidence

Require correct coordinate mappings, feature changes and an explanation of parameter nonuniqueness. Verify supplied correspondences; visual resemblance alone does not determine them.

### Sketching from verified attributes

Curriculum reference: **Sketching from verified attributes** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Sketch $y=(x-2)^2-4$ from verified attributes.

**Agent key:** Vertex $(2,-4)$, axis $x=2$, zeros 0 and 4, y-intercept 0, opens upward. Points symmetric about the axis must agree.

**Worked example:** A sketch of $-x^2+4x-1$ shows vertex $(2,3)$ but opens upward. Diagnose it.

**Worked reasoning:** Completing the square gives $-(x-2)^2+3$; vertex is correct but the negative leading coefficient requires downward opening.


#### Teaching sequence

Assemble a graph from exact anchors: opening, vertex, axis, intercepts and at least one symmetric pair. Substitute those points into the original formula, then draw a smooth parabola consistent with them. A correct vertex does not excuse an incompatible opening or range. Separate a symbolic sketch from an actual graphing-tool observation.

#### Respond to student reasoning

**First hint:** Do the opening direction and vertex agree with the formula?

If points fail symmetry, compare equal distances from h. If a negative leading coefficient opens upward, complete the square to locate the sign. If intercepts are estimated from a rough picture, return to exact algebra before marking them exact.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Sketch from vertex, factored and standard forms; then diagnose a plausible-looking graph with one inconsistent attribute. When technology is required, compare predicted coordinates with actual output.

#### Assessment evidence

Assess consistency among formula, anchors, symmetry, opening and range. Record any required tool verification separately and accept an exact accessible graph description when a drawing itself is not the assessed requirement.
