# Lesson 21.4: Literal equations and parameter cases

Solving for a selected symbol reveals formulas in a useful form while requiring attention to coefficients that may be zero.

## Learning objectives

- Rearrange formulas to isolate a selected variable.
- State parameter restrictions and classify exceptional cases in linear literal equations.

## Proficiency criteria

- Treat other symbols as parameters and distinguish legal division from an assumed nonzero coefficient.
- Give separate zero-coefficient cases when they change the solution set.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Rearranging literal formulas** | A literal equation relates several symbols. Isolating one quantity uses the same equality properties as numerical equations; collecting its terms and extracting a common factor may be required. Division introduces a condition that the divisor be nonzero. Units can check the dimensional compatibility of the rearranged formula. | Rearrange linear literal formulas for a specified variable, including variables occurring in multiple terms, and state restrictions. | Isolate the requested variable, preserve the meanings of parameters and units, and record every nonzero assumption introduced by division. |
| **Linear parameter classification** | For \(a x+b=c\), the formula \(x=(c-b)/a\) applies only when \(a\ne0\). When \(a=0\), the equation has all permitted real inputs if \(b=c\), and no solutions if \(b\ne c\). More complicated linear formulas reduce to the same coefficient cases. | Classify and solve linear equations with symbolic coefficients, including zero-coefficient and identity cases. | State mutually exhaustive parameter conditions, avoid dividing before checking a possibly zero expression, and distinguish an unrestricted real solution set from contextual restrictions. |
