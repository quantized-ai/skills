# Unit 21: Linear equations and literal formulas

This unit defines equations as conditions on possible values, develops justified linear solution methods, and applies the same reasoning to formulas and contextual relationships.

## Main learning objectives

- Solve linear equations with real and rational coefficients while justifying solution-preserving operations.
- Classify equations with one solution, no solutions, or all permitted values as solutions.
- Rearrange literal formulas, handle parameter exceptions, and interpret solutions in linear models.

## Concepts and topics

Equality; solution sets; inverse operations; multistep equations; variables on both sides; fraction and decimal coefficients; contradictions and identities; parameter cases; literal formulas; cost, mixture, and motion models.

## Lessons

- [21.1: Equality and inverse operations](lesson-1-equality-and-inverse-operations/lesson.md) — An equation specifies equal values, and solving identifies all values that make the original statement true.
- [21.2: Multistep linear equations and solution counts](lesson-2-multistep-linear-equations-and-solution-counts/lesson.md) — Distribution and collection of like terms reduce linear equations to forms that reveal both solutions and exceptional cases.
- [21.3: Fraction and decimal coefficients](lesson-3-fraction-and-decimal-coefficients/lesson.md) — Clearing numerical denominators or decimal places changes a linear equation to a convenient equivalent equation.
- [21.4: Literal equations and parameter cases](lesson-4-literal-equations-and-parameter-cases/lesson.md) — Solving for a selected symbol reveals formulas in a useful form while requiring attention to coefficients that may be zero.
- [21.5: Linear equation models](lesson-5-linear-equation-models/lesson.md) — Linear modeling turns relationships among defined quantities into solvable equations and tests the resulting values against the situation.
