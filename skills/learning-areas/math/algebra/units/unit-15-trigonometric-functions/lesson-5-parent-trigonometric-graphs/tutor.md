**Prompt:** A tangent sketch joins values across x=π/2 with a vertical segment. Why is that not part of the graph?

**Private reasoning key:** Tangent is undefined at π/2 because cosine is zero. The line is an asymptote, not a set of attained values; adjacent branches remain disconnected.

Ask what changed between the original claim and the repaired explanation. If the response is only a guessed answer, use the corresponding concept’s targeted cue below; after feedback, collect a new independent attempt.

## Concept guidance

### Sine and cosine graphs

Curriculum reference: **Sine and cosine graphs** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Give sine's values at 0,π/2,π,3π/2,2π and its range.

**Agent key:** Values 0,1,0,-1,0 anchor a smooth cycle; range [-1,1] and period 2π.

**Worked example:** Compare cosine's starting value and zeros with sine's.

**Worked reasoning:** Cosine starts at 1 and has zeros π/2+kπ; sine starts at 0 and has zeros kπ. Their phases differ.


#### Teaching sequence

Trace one turn's unit-circle coordinates to build sine and cosine anchor points, connecting them as smooth periodic curves rather than straight segments. Mark zeros and extrema, then repeat cycles with the correct period. Compare their phase positions while preserving common range and amplitude. Use exact multiples of π before numerical plotting.

#### Respond to student reasoning

**First hint:** Which unit-circle coordinate is being plotted?

If anchors are connected by straight lines as the exact graph, compare an intermediate angle's value. If sine starts at one, revisit the point at angle zero. If both end anchors are counted as different phase positions, recognize the repeated cycle boundary.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Sketch several cycles, read features from exact graph descriptions and connect a unit-circle position with its graph point. Compare sine and cosine phase shifts.

#### Assessment evidence

Require consistent anchors, smooth shape, zeros/extrema, range and period, plus a coordinate interpretation. Record actual graph-tool observations separately when required.

### Tangent graph and asymptotes

Curriculum reference: **Tangent graph and asymptotes** in the [curriculum concept table](lesson.md#concepts). Read that row’s Content, Learning Objectives, and Proficiency criteria before using these activities.

#### Calibration and worked reasoning

**Diagnostic prompt:** Describe one branch of tan x between -π/2 and π/2.

**Agent key:** It increases from negative unbounded values to positive unbounded values, crosses (0,0), and excludes both vertical asymptotes.

**Worked example:** Does tangent have amplitude 1 because it has period π?

**Worked reasoning:** No. Tangent has all-real range and no finite amplitude; period does not imply bounded outputs.


#### Teaching sequence

Define tangent as sine/cosine and locate forbidden inputs where cosine is zero. Between −π/2 and π/2 it passes through zero and increases without bound toward each open vertical boundary in opposite directions. Repeat with period π, keeping branches disconnected. Its all-real output range means it has no finite amplitude.

#### Respond to student reasoning

**First hint:** Where does cosine vanish in the sine-over-cosine definition?

If branches are joined across an asymptote, ask for the value at the separating input. If period is mistaken for amplitude, distinguish horizontal repetition from vertical extent. If the axis crossing is called an asymptote, evaluate tangent there.

Give only the cue relevant to the observed error; wait for a revision before showing a worked step. Record any mathematical help as assistance.

#### Practice progression

Draw or describe successive branches, locate zeros/asymptotes in a stated interval and compare with bounded sine/cosine behavior.

#### Assessment evidence

Assess domain exclusions, period, zeros, branch monotonicity and range/no-amplitude distinction. Do not plot infinity as an attained output.

Use the [fresh-question policy](../question-generation.md); the two calibration examples above are exposed learning material, not the default quiz. Collect the curriculum's full proficiency evidence, retain demonstrated components, and reassess unresolved cases with new tasks.

## Decision model and graduated practice

Sine graphs the vertical unit-circle coordinate against angle, so the quarter-turn values $0,1,0,-1,0$ at $0,\pi/2,\pi,3\pi/2,2\pi$ form a full smooth cycle. Cosine uses horizontal coordinates $1,0,-1,0,1$. Connecting these anchors periodically must preserve their different phase positions.

If a learner swaps sine and cosine, cue “Which coordinate is being tracked at angle zero?”; then draw or name point $(1,0)$; next identify sine there as $0$, leaving the remaining anchors. Fade by asking the learner to extend one cycle leftward using symmetry. For tangent, use anchors $(-\pi/4,-1),(0,0),(\pi/4,1)$ between excluded endpoints $\pm\pi/2$. The quotient's denominator approaches zero there; branches are separate, and the asymptote is not a vertical segment of the graph. Its unbounded outputs prevent a finite amplitude.
