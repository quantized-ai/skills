# Unit 22: One-variable linear inequalities

This unit represents ordered constraints as sets of possible values and develops justified methods for individual and compound inequalities.

## Main learning objectives

- Represent real solution sets with inequalities, number lines, intervals, and set-builder notation.
- Solve and classify linear inequalities, including symbolic-coefficient cases.
- Combine and interpret inequalities as simultaneous or alternative constraints.

## Concepts and topics

Strict and inclusive order; interval and set notation; inequality-preserving operations; sign reversal; empty and universal sets; symbolic coefficients; compound inequalities; contextual and integer restrictions.

## Lessons

- [22.1: Inequalities and solution-set notation](lesson-1-inequalities-and-solution-set-notation/lesson.md) — An inequality describes a set of inputs, and several notations communicate its extent and endpoint inclusion.
- [22.2: Solving and classifying linear inequalities](lesson-2-solving-and-classifying-linear-inequalities/lesson.md) — Ordered comparisons require sign-sensitive operations to preserve their solution sets.
- [22.3: Compound inequalities and contextual constraints](lesson-3-compound-inequalities-and-contextual-constraints/lesson.md) — Intersections and unions combine ordered constraints, while contexts can further restrict the permissible values.
