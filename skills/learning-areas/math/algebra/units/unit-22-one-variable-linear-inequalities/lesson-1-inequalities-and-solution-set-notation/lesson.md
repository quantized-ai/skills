# Lesson 22.1: Inequalities and solution-set notation

An inequality describes a set of inputs, and several notations communicate its extent and endpoint inclusion.

## Learning objectives

- Interpret and verify inequality solutions.
- Translate between inequalities, graphs, intervals, and set-builder descriptions.

## Proficiency criteria

- Distinguish strict from inclusive endpoints and value from magnitude comparisons.
- Use infinity as an unbounded direction, never an included real endpoint.

## Concepts

| Concept Title | Content | Learning Objectives | Proficiency criteria |
| --- | --- | --- | --- |
| **Order statements and membership** | \(<\) and \(>\) are strict; \(\le\) and \(\ge\) include equality. A solution is a value making the original statement true and defined. A real inequality usually describes a set of values, and contextual constraints may restrict the permitted domain to integers or a bounded interval. | Interpret inequality statements and determine whether specified values belong to their solution sets. | Check the original comparison, distinguish endpoint membership, and apply the stated domain before declaring a value a solution. |
| **Number lines, intervals, and set-builder notation** | Open endpoints exclude values and closed endpoints include them. Interval parentheses and brackets encode the same distinction; infinity symbols always use parentheses. Unions describe alternatives and intersections describe shared membership. Set-builder notation states a domain and condition; the empty set and all real numbers have distinct meanings. | Represent inequality solution sets with number lines, interval notation, and set-builder notation, including empty and unbounded sets. | Preserve endpoint inclusion and every component of a union, use infinity only for unboundedness, and distinguish a set from an individual endpoint. |
