## Reasoning and error-analysis activity

**Ask:** −2x≥8 is solved asx≥−4. Ask the student to locate the first invalid inference, repair the reasoning, and explain a check or counterexample.

**Private reasoning and response:** Dividing by a negative reverses order: x≤−4. Testx=0 to expose the error; ask for a number-line reflection explanation.

If the student gives only a corrected answer, ask why the original method failed. If the reason is secure, request a different example where the distinction matters. If they remain stuck, use the targeted response below for the relevant concept and mark the attempt assisted.

## Concept teaching plans

### Equivalent inequality transformations

**Diagnostic — ask and wait:** Solve −3x<12.

**Private diagnostic key:** x>−4.

**Teach in this order:** Add/subtract like equality operations; explicitly identify negative scaling; explain reversal using ordered numbers or reflected number line; test both sides of boundary.

**Distinct worked model — reveal in steps:** $5-2x\ge11$ gives −2x≥6 then x≤−3. Dividing by a negative reverses order; at x=−4 the original left side 13 satisfies≥11, while x=0 does not.

**Misconception response and hint ladder:** If direction is retained, ask whether −6<−3 becomes 2<1 after dividing by−3; next use that contradiction to motivate reversal. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Positive coefficient → negative coefficient → parentheses/fractions with boundary checks. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Correct reversal only under negative scale; strictness retained; equivalent steps; test points. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Apply operations to complete sides, reverse the comparison for negative multiplication or division, and represent and verify the full resulting solution set.

### Constant and symbolic-coefficient cases

**Diagnostic — ask and wait:** Solve 0x<2.

**Private diagnostic key:** all real x.

**Teach in this order:** Determine coefficient sign before division; split positive/negative/zero cases; evaluate constant statements separately.

**Distinct worked model — reveal in steps:** For ax≤6: a>0 gives x≤6/a; a<0 gives x≥6/a; a=0 gives all real x because 0≤6. For 0x≤−1 there are none. The sign of a cannot be guessed.

**Misconception response and hint ladder:** If x≤6/a is given without cases, ask whether a could be−2 or0; next substitute each and compare. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Constant true/false → unknown-sign coefficient → parameter thresholds. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Exhaustive sign cases; no division by0; all/empty sets; original relation. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Give complete parameter cases, retain strictness or inclusion, and never divide by a quantity of unknown sign without branching.

## Extended private calibration

**Prompt:** Solve $-3x+4\le10$. Then classify $ax<6$ according to the sign of a.

**Private worked key:** Subtract 4 and divide by -3, reversing order: $x\ge-2$. For $a>0$, $x<6/a$; for $a<0$, $x>6/a$; for $a=0$, $0<6$ is true for all real x.

This previously checked composite example can connect concepts after instruction. Split it into manageable turns; it does not replace the distinct diagnostic and worked model for each concept.
