## Concept teaching plans

### Operation properties and exceptions

**Diagnostic — ask and wait:** Is a−b=b−a always true?

**Private diagnostic key:** no; a=5,b=2 gives 3 versus −3.

**Teach in this order:** Name the operation before a property; show regrouping versus reordering; use counterexamples for invalid extensions.

**Distinct worked model — reveal in steps:** $7+(x+3)=(7+3)+x=10+x$ uses associativity and commutativity of addition. Multiplication has corresponding properties; subtraction/division do not. Zero is additive identity, one multiplicative identity.

**Misconception response and hint ladder:** If associativity is claimed for division, ask to compare (12/3)/2 and 12/(3/2); next calculate 2 versus 8. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Identify properties → justify a simplification → refute an invalid operation analogy. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Commutative/associative/distributive roles; identities/inverses; subtraction/division exceptions; zero restrictions. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Name the property supporting a rewrite, preserve the grouped operation, and identify why a proposed subtraction, division, or zero-reciprocal step fails.

### Distribution and common linear structure

**Diagnostic — ask and wait:** Expand −2(x−5).

**Private diagnostic key:** −2x+10.

**Teach in this order:** Draw equal groups or an area partition; distribute to every term; reverse the process using the common factor; verify by expansion.

**Distinct worked model — reveal in steps:** $6x+9=3(2x+3)$ because both terms contain 3. Expanding checks the factorization. For $a(b+c)$, multiplication reaches each addend; distributing a negative factor changes each product sign.

**Misconception response and hint ladder:** If−2(x−5) becomes −2x−10, ask for (−2)(−5); next write both products before combining. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Positive distribution → negative/fractional factor → extract common linear structure. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Every term multiplied; sign; factorization as inverse; exact equivalence; no illegal distribution through unrelated operations. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Multiply every term by the outside factor, retain negative and fractional coefficients, and verify reverse distribution by expansion.

## Extended private calibration

**Prompt:** Rewrite $3(2x-5)-2(x+1)$ and justify the properties. Factor $6x+9$. Is subtraction commutative?

**Private worked key:** Distribution gives $6x-15-2x-2=4x-17$. Factoring gives $3(2x+3)$. Subtraction is not commutative: $5-2=3$ but $2-5=-3$. Distribution acts on every term including its sign.
