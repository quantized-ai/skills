## Reasoning and error-analysis activity

**Ask:** Equal ratios at x=0,2,4 are interpreted as the per-unit factor; an excluded endpoint is called a maximum. Ask the student to locate the first invalid inference, repair the reasoning, and explain a check or counterexample.

**Private reasoning and response:** The ratio spans two input units, so take a positive square root for a per-unit exponential factor. An extremum needs an allowed attaining input. Ask the student to label input gaps and endpoint inclusion separately.

If the student gives only a corrected answer, ask why the original method failed. If the reason is secure, request a different example where the distinction matters. If they remain stuck, use the targeted response below for the relevant concept and mark the attempt assisted.

## Concept teaching plans

### Differences, ratios, shape, and context

**Diagnostic — ask and wait:** Inputs 0,2,4 have outputs 3,6,12. What is the per-unit factor?

**Private diagnostic key:** √2, not 2, since each doubling spans two input units.

**Teach in this order:** Verify spacing before applying a pattern test; distinguish additive and multiplicative changes; connect the candidate to domain and long-term contextual behavior.

**Distinct worked model — reveal in steps:** At x=0,1,2,3, values 2,5,10,17 have differences 3,5,7 and second differences 2,2, supporting $x^2+2x+2$. A finite table supports this candidate but other functions can pass through the points.

**Misconception response and hint ladder:** If differences at unequal spacing are compared directly, ask for change per input unit; next tabulate both input gaps and output gaps. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Equal-gap exact tables → unequal-gap or noisy tables → rule out a family using context and graph shape. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Linear/quadratic/exponential patterns; positive ratios; unequal spacing; approximate patterns; non-uniqueness from finite data. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Check input spacing and ratio validity before interpreting first differences, second differences, or output ratios. Identify candidates consistent with exact or approximate patterns and qualify conclusions drawn from finite data. Use contextual behavior and graph shape to justify a family and any necessary domain restriction.

### Comparing representations and rates

**Diagnostic — ask and wait:** A graph passes through (1,4),(4,10). Its average rate is?

**Private diagnostic key:** 2 output units/input unit; this does not assert a straight graph.

**Teach in this order:** Choose a common interval and units; read endpoints from each representation; form signed differences; separate output level from rate.

**Distinct worked model — reveal in steps:** Compare $f(t)=t^2$ and a table for g with g(1)=2,g(3)=10. On [1,3] both average rates are 4, yet f(1)=1 differs from g(1)=2. Equal secant slopes do not imply identical values or local changes.

**Misconception response and hint ladder:** If equal average rates imply equal functions, ask for starting values; next compare the two endpoint pairs explicitly. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Equation/table comparison → graph/verbal comparison → same average with different behavior. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** Compatible intervals/units; secant interpretation; outputs/intercepts and represented turning/end behavior; no inference of constant rate from one average. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Calculate secant rates from compatible input-output values and state output-per-input units. Compare rates and supported graph features on compatible domains without confusing initial level, final level, and average change. Distinguish an interval average from constant change and distinguish observed features from unverified behavior.

### Extrema on specified intervals

**Diagnostic — ask and wait:** Does $2^x$ have a minimum on (0,2]?

**Private diagnostic key:** no; 1 is an unattained lower bound; maximum 4 occurs at 2.

**Teach in this order:** Intersect domains; mark open/closed endpoints and singularities; use monotonicity or absolute-value turning point; distinguish an attained value from an approaching bound.

**Distinct worked model — reveal in steps:** For $\log_{1/2}x$ on [1/4,2), the function decreases. Maximum is 2 at 1/4; values approach −1 as x approaches 2, but no minimum is attained. Domain x>0 must be checked before the interval.

**Misconception response and hint ladder:** If an open endpoint supplies an extremum, ask which allowed input attains it; next compare values closer to that endpoint. If the first prompt is insufficient, use the next indicated representation/setup; only then reveal one calculation or inference. Ask the student to finish the remaining reasoning.

**Practice progression:** Closed monotone interval → interior absolute-value minimum → open endpoint/singularity and decreasing exponential/log base. Change a meaningful case or representation before increasing arithmetic size. Reuse the student's error as the focus of a new task, not by repeating an exposed answer.

**Assessment case checklist:** All seven parents: square root, reciprocal, cubic, cube root, absolute value, exponential, logarithm; restricted domain; attainment; unbounded cases. Select independent tasks that collectively cover these cases and the curriculum row's full proficiency; a short session may leave named cases unassessed.

**Curriculum evidence contract:** Restrict the interval to allowed inputs and identify excluded endpoints and singularities. Use monotonicity, symmetry, endpoint values, and interior turning points to determine whether extrema exist. State and compare extrema with their attaining inputs; justify any unattained bound or unbounded direction.

## Extended private calibration

**Prompt:** At inputs 0,1,2,3, compare outputs A: 2,5,8,11; B: 2,6,18,54; C: 1,2,5,10. Compare average rates of A and B from 0 to 2. Find extrema of $1/x$ on $(0,2]$ and $|x|$ on $[-2,3)$.

**Private worked key:** A supports linear $2+3t$ by equal first differences; B supports exponential $2\cdot3^t$ by equal ratios; C supports quadratic $t^2+1$ by equal second differences. These finite data do not prove a unique global model. Rates over $[0,2]$ are 3 and 8 output units per input unit; this does not make B a constant-rate model. For $1/x$ on $(0,2]$, minimum is $1/2$ at x=2 and no maximum, since it is unbounded above near 0. For $|x|$ on $[-2,3)$, minimum is 0 at x=0; upper bound 3 is unattained, so no maximum.

This previously checked composite example can connect concepts after instruction. Split it into manageable turns; it does not replace the distinct diagnostic and worked model for each concept.

## Additional worked coverage

Additional parent-family checks: $\sqrt x$ on $[-1,4)$ has restricted domain $[0,4)$, minimum 0 at 0 and no maximum (upper bound 2). $x^3$ on $(-1,2]$ has maximum 8 at 2 and unattained lower bound −1. $\sqrt[3]x$ on $[-8,1]$ has minimum −2 and maximum 1 at the endpoints. $(1/2)^x$ on $[0,2]$ has maximum 1 at 0 and minimum 1/4 at 2. $\log_2 x$ on $(0,4]$ has maximum 2 at 4 and is unbounded below. Ask for the attaining input whenever a student claims an extremum.

Use this reasoning as instruction or private calibration. Generate a fresh independent counterpart after exposure; this is not a fixed reassessment task.


## Further task construction

Vary family, input spacing, context, graphical features and represented rates; include extrema of all seven specified parent families (square-root, reciprocal, cubic, cube-root, absolute value, exponential and logarithmic), open endpoints, singularities and decreasing bases between zero and one.
