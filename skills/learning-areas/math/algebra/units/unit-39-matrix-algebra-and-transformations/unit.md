# Unit 39: Matrix algebra and transformations

Matrices organize quantitative relationships and define linear transformations. Dimension-aware arithmetic leads to determinants, inverses, matrix equations for systems, and geometric interpretations of planar transformations.

## Main learning objectives

- Represent data with matrices and perform scalar multiplication, addition, subtraction, and compatible matrix products.
- Explain matrix algebra properties and the roles of zero matrices, identity matrices, determinants, and inverses.
- Solve matrix-form linear systems and interpret matrix transformations, composition, and area scaling.

## Concepts and topics

Dimensions and labels; matrix data models; scalar and matrix arithmetic; noncommutativity; associative and distributive properties; zero and identity matrices; determinants; inverse criteria; linear systems; vector transformations; plane transformations and area.

## Lessons

- [39.1: Matrices as data representations](lesson-1-matrices-as-data-representations/lesson.md) — Matrix entries have meaning through row labels, column labels, and units; a useful representation must preserve those meanings under manipulation.
- [39.2: Matrix arithmetic and products](lesson-2-matrix-arithmetic-and-products/lesson.md) — Matrix arithmetic requires matching dimensions, and a matrix product uses row-column sums rather than entrywise multiplication.
- [39.3: Matrix algebra, zero, and identity](lesson-3-matrix-algebra-zero-and-identity/lesson.md) — Matrix operations share some real-number algebra properties while differing in commutativity and cancellation. Zero and identity matrices depend on dimensions.
- [39.4: Determinants, inverses, and linear systems](lesson-4-determinants-inverses-and-linear-systems/lesson.md) — A square matrix has an inverse exactly when its determinant is nonzero. This criterion connects reversible transformations to unique solutions of matrix-form linear systems.
- [39.5: Matrix transformations and area](lesson-5-matrix-transformations-and-area/lesson.md) — Matrix-vector multiplication defines linear transformations that preserve the origin. Two-by-two matrices describe familiar planar maps and reveal determinant-based area scaling.
